SCENARIO 1: Template Not Approved Yet
─────────────────────────────────────────────────────────────────

│  ❌ Failed to send WhatsApp message                      │
└─────────────────────────────────────────────────────────┘

User thinks: "What? Why? What should I do?"


✅ AFTER (Detailed):
┌─────────────────────────────────────────────────────────┐
│  ❌ WhatsApp template not found or not approved yet.     │
│                                                         │
│  💡 Suggestion: Wait for template approval (1-3 days)   │
│     or use Custom Text mode instead.                    │
│                                                         │
│  Code: 20404                                            │
└─────────────────────────────────────────────────────────┘

User knows: "Ah! Template bado review. Nitumia SMS kwanza!"

SCENARIO 5: Sandbox Not Joined
─────────────────────────────────────────────────────────────────

❌ BEFORE (Silent fail):
┌─────────────────────────────────────────────────────────┐
│  ✅ Sent successfully                                    │
└─────────────────────────────────────────────────────────┘

(But guest never receives anything!)


✅ AFTER (Explains why):
┌─────────────────────────────────────────────────────────┐
│  ❌ 📱 Recipient has not joined WhatsApp Sandbox        │
│     or WhatsApp Business API not enabled.               │
│                                                         │
│  💡 Suggestion: Either:                                 │
│     1) Wait for WhatsApp Business approval              │
│     2) Ask guest to send "join <code>" to sandbox       │
│                                                         │
│  Code: 63016                                            │
└─────────────────────────────────────────────────────────┘

User: "Ah! Nisubiri approval ya Business API. SMS kwanza!"

  21211 - Invalid format
  21608 - Not on WhatsApp
  21610 - Number blocked sender

  20429 - Insufficient balance
  429   - Rate limit exceeded

  ENOTFOUND - Cannot connect
